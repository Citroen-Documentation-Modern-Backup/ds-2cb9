C5JG013JP0Dépose - Repose : Pare-chocs arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
1.1. Opérations communes
Mettre le véhicule sur un pont élévateur deux colonnes.
Déposer les pare-boue arrière .
1.2. Véhicule avec portes arrière battantes
Ouvrir les portes arrière.
Déchausser : Le joint d’entrée de portes battantes arrière  (en partie inférieure).

Déconnecter le connecteur  (en "a").
Figure : c5jm0f2d
Déposer les vis (1) (de chaque côté).
Figure : c5jm0f3d
Déposer les vis (2).
Figure : c5jm0f4d
Déposer les vis (3).
Dégager le pare-chocs arrière (4) (suivant flèche ).
Figure : c5jm0f5d
NOTA : Pour l’opération suivante, 2 opérateurs sont nécessaires.
Déposer le pare-chocs arrière (4).
1.3. Véhicule avec volet arrière
Ouvrir le volet arrière .
Déchausser : Le joint d’entrée de volet arrière  (en partie inférieure).
Déposer les feux arrière .

Déconnecter le connecteur  (en "b").

Déposer les vis (5) (de chaque côté).

Déposer les vis (6).
Figure : c5jm0f9d
Déposer les vis (7), (8).
Dégager le pare-chocs arrière (9) (suivant flèche ).
Figure : c5jm0fad
NOTA : Pour l’opération suivante, 2 opérateurs sont nécessaires.
Déposer le pare-chocs arrière (9).
2. Repose
2.1. Véhicule avec portes arrière battantes
Procéder dans l’ordre inverse des opérations de dépose.
Serrer :
  • Les vis (1) à 0,85 ± 0,15 m.daN
  • Les vis (2), (3) à 0,25 ± 0,05 m.daN
2.2. Véhicule avec volet arrière
Procéder dans l’ordre inverse des opérations de dépose.
Serrer :
  • Les vis (5), (7) à 0,85 ± 0,15 m.daN
  • Les vis (6), (8) à 0,25 ± 0,05 m.daN
2.3. Opérations communes
Reposer les pare-boue arrière .
Vérifier le fonctionnement des différents équipements.
