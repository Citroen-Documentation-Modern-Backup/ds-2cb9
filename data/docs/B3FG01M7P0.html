B3FG01M7P0Dépose - repose : Pompe à vide électrique
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
Mettre le véhicule sur un pont élévateur deux colonnes.
Figure : b3fg2kud
Désaccoupler le raccord encliquetable de la pompe à vide électrique (en "a").
Dégrafer :
  • Le connecteur (en "c")
  • Le faisceau électrique  (en "d")
Déconnecter le connecteur (en "b").
Déposer l’écrou (1).
Figure : b3fg2kvd
Dégrafer et écarter le tube (4) (en "e").
Déposer :
  • Les 3 écrous (3)
  • Le couvercle (2)
Figure : b3fg2kwd
Déposer la pompe à vide électrique (5).
2. À l’établi
2.1. Déshabillage
Figure : b3fg2kxd
Déposer :
  • Les 3 vis (6)
  • Le support (7)
2.2. Habillage
Reposer :
  • Le support (7)
  • Les 3 vis (6)
3. Repose
ATTENTION : Respecter les couples de serrage .
Reposer :
  • La pompe à vide électrique (5)
  • Le couvercle (2)
  • Les 3 écrous (3)
  • L’écrou (1)
Agrafer le tube (4) (en "e").
Connecter le connecteur  (en "b").
Agrafer :
  • Le faisceau électrique  (en "d")
  • Le connecteur (en "c")
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie de servitude.
Rebrancher la batterie de servitude .
