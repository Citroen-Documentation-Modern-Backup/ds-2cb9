2. Dépose
IMPERATIF : Moteur chaud : Attendre au minimum une heure avant toute intervention sur la ligne d’échappement.
Mettre le véhicule sur un pont élévateur.
Débrancher la batterie .
Figure : b1bm07ld
Déposer le raccord (1).
NOTA : Pour accéder à la vis de fixation du protecteur thermique.
Figure : b1km01rd
Déposer :
  • Le capteur de pression gaz d’échappement
  • La vis (3)
  • La patte de fixation (4) (Tubes (2) de prise de pression de gaz d’échappement)
Figure : b1km01sd
ATTENTION : Desserrer les 2 vis (6) (Au maximum) ; Problème d’accessibilité.

Desserrer les 2 vis (6) (Au maximum) ; Sans déposer.
Figure : b1km01td
Desserrer les raccords (7).
Déposer :
  • Le tube de prise de pression (Amont) : Par le dessus du véhicule
  • Le tube de prise de pression (Aval ) : Par le dessous du véhicule ; Écarter sans forcer le protecteur thermique
Figure : b1km01ud
ATTENTION : Repérer l’orientation et l’appariement des tubes de prise de pression souples sur les tubes (2) avant de les désaccoupler.
Déposer : Les colliers CLIC (8).
Désaccoupler les tubes de prises de pression souples des tubes (2) de prise de pression (Tubes métalliques).
Obturer les tubes de prise de pression et les conduits de prise de pression de l’ensemble précatalyseur/ filtre à particules ; À l’aide de l’outil [1].
3. Repose
ATTENTION : Remplacer les colliers "clic" déposés par des neufs.
ATTENTION : Accoupler les tubes de prise de pression souples sur les tubes (2) dans l’orientation et l’appariement repérés lors de la dépose.
Serrer les raccords (7) des tubes de prises de pression à 2 ± 0,5 m.daN.
Reposer :
  • Les vis (5), (6)
  • La patte de fixation (4)
  • La vis (3)
  • Le capteur de pression gaz d’échappement
  • Le raccord (1)
Rebrancher la batterie.
