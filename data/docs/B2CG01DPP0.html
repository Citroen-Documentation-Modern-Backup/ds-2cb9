B2CG01DPP0Dépose - Repose : Capteur de point mort de commande de vitesses
BVM BE4R ET BVM 5 RAPPORTS TYPE STT
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opération préliminaire
Déposer :
  • La batterie
  • Le bac à batterie
  • Le support de boîte de vitesses
2. Dépose
Figure : b2cg1w1d
Déconnecter le connecteur  (en "a").
Déclipper le faisceau électrique  (en "b").
ATTENTION : Ne pas tirer sur le faisceau pour déposer le capteur (2).
Déposer :
  • La vis (1)
  • Le capteur (2)
3. Repose
Figure : b2cg1w4d
ATTENTION : Remplacer le joint (3) du capteur de point mort à chaque dépose.
ATTENTION : Respecter les couples de serrage.
Figure : b2cg1w5d
Reposer le capteur (2) dans son logement jusqu’au niveau du joint, enfoncer le capteur en s’appuyant sur la partie extérieure du capteur (en "c").
Reposer la vis (1).
Clipper le faisceau électrique  (en "b").
Connecter le connecteur  (en "a").
4. Opération complémentaire
Reposer :
  • Le support de boîte de vitesses
  • Le bac à batterie
  • La batterie
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
