3. Contrôle
IMPERATIF : Lors de l’accouplement des outils [0141-T1], [1604-A / 4073-T.A] se protéger à l’aide d’un chiffon, afin d’éviter toute projection de carburant.
Raccorder l’outil [0141-T1] sur la valve de purge du circuit d’alimentation carburant (en "a").
Accoupler l’outil [1604-A / 4073-T.A] avec l’outil [0141-T1].
Démarrer le moteur.
Relever la pression ; À l’aide de l’outil [1604-A / 4073-T.A].
Pression de fonctionnement 3,5 bars.
Arrêter le moteur.
NOTA : Si la valeur relevée est incorrecte, rechercher l’origine de la panne.

ATTENTION : Se munir d’un récipient pour récupérer le carburant.
