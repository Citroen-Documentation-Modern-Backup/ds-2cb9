D1AG015WP0Dépose - repose : Connecteurs haute tension
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Seules les personnes ayant reçu une formation spécifique aux véhicules électriques ou hybrides sont habilitées à intervenir sur le réseau électrique de traction du véhicule et sur les composants directement alimentés par la batterie de traction (respecter la réglementation en vigueur dans le pays concerné).
IMPERATIF : Mettre le véhicule hors tension .
1. Matériel
Une nappe isolante .
1 Kit de sacs isolants.
Ruban adhésif (Orange).
2. Dépose
Figure : d1ag0vwd
Déverrouiller la languette (1) (suivant flèche ).
Figure : d1ag0vxd
Déverrouiller le levier (2) (en "a") (suivant flèche ).
ATTENTION : Manipuler le levier (2) à deux mains.
Basculer complètement le levier (2).
Figure : d1ag0vyd
Vérifier que le levier (2) est en fin de course (En "b" et "c").
Figure : d1ag0vzd
ATTENTION : Ne pas mettre le connecteur de travers.
Déconnecter le connecteur (en "d").
3. Protection
Figure : d1ag0kld
"A" : Connecteur 3 voies .
"B" : Connecteur 2 voies .
"C" : Connecteur 1 voie.
Rabattre le levier (2).
Placer le connecteur dans un sac isolant  [1] ou [2].
NOTA : Choisir la taille du sac isolant en fonction du connecteur.
Fermer le sac isolant [1].
Figure : d1ag0kmd
"D" : Connecteur 3 voies .
"E" : Connecteur 2 voies .
"F" : Connecteur 1 voie.
À réaliser :
  • Une nappe isolante [4] 15 x 15 mm (Pour un connecteur 1 ou 2 voies)
  • Une nappe isolante [3] 20 x 15 mm (Pour un connecteur 3 voies)
Poser une nappe isolante [4] sur le connecteur (côté élément) ; Fixer à l’aide de ruban adhésif orange.
4. Vérification
Vérifier visuellement l’état du connecteur :
  • Absence de trace de choc
  • Absence de corps étranger
  • Absence d’humidité
  • Absence d’oxydation
  • Absence de fissure
Vérifier visuellement l’état des câbles électriques :
  • Absence de pincement
  • Absence de déchirure
  • Absence de coupure
  • Absence d’humidité
5. Repose
Déposer :
  • La nappe isolante
  • Le sac isolant
Figure : d1ag0w0d
Basculer le levier (2).
Vérifier que le levier (2) est en fin de course (en "e").
Figure : d1ag0w1d
ATTENTION : Ne pas mettre le connecteur de travers.
Enclencher le connecteur  (en "b") (suivant flèches).
Figure : d1ag0w2d
ATTENTION : Manipuler le levier (2) à deux mains.
Rabattre le levier (2).
Verrouiller la languette (1).
Figure : d1ag0w3d
ATTENTION : Risque de mauvais verrouillage du connecteur haute tension.
Contrôler les points suivants :
  • Vérifier visuellement l’enclenchement correct du levier (2) (en "b")
  • Vérifier manuellement le verrouillage du connecteur
6. Opérations complémentaires
Mettre le véhicule sous tension .
ATTENTION : Le verrouillage de tous les connecteurs haute tension doit être correctement réalisé : Risque d’apparition de codes défauts dans le calculateur véhicule électrique.
ATTENTION : Vérifier l’absence de défaut ; À l’aide de l’outil de diagnostic.
Effectuer un essai routier.
