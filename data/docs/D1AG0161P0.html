D1AG0161P0Dépose - repose : Cadre support de l’ensemble machine électrique - réducteur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Seules les personnes ayant reçu une formation spécifique aux véhicules électriques ou hybrides sont habilitées à intervenir sur le réseau électrique de traction du véhicule et sur les composants directement alimentés par la batterie de traction (respecter la réglementation en vigueur dans le pays concerné).
IMPERATIF : Mettre le véhicule hors tension .
1. Matériel
Chandelle hydraulique.
2. Opérations préliminaires
Vidanger :
  • Le circuit de refroidissement
  • Le réducteur
3. Dépose
Déposer :
  • La batterie de servitude
  • Le boîtier de jonction
  • Le chargeur embarqué
  • Le calculateur de contrôle machine électrique
  • L’ensemble machine électrique - réducteur
Figure : d1ag0xyd
Dégrafer :
  • Les faisceaux attenants au cadre support de l’ensemble machine électrique - réducteur (1)
  • Les durits de refroidissement attenant au cadre support de l’ensemble machine électrique - réducteur (1)
Déposer le support de la batterie servitude (2).
Déposer et écarter la pompe à vide électrique (3).
Figure : d1ag0xzd
Dégrafer les faisceaux (en "a", "b").
Figure : d1ag0y0d
ATTENTION : Protéger le radiateur de refroidissement pour éviter d’abîmer les ailettes.
Sangler le cadre support de l’ensemble machine électrique - réducteur (1).
Déposer les vis (5), (4).
Figure : d1ag0y1d
Placer une chandelle hydraulique sous le cadre support de l’ensemble machine électrique - réducteur (1).
Déposer la sangle .
Déposer (Par le dessous) :
  • Les 2 vis (6)
  • Le cadre support de l’ensemble machine électrique - réducteur (1)
4. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Éléments de la chaîne de traction électrique
  • Suspension ensemble machine électrique - réducteur
Reposer le cadre support de l’ensemble machine électrique - réducteur (1) ; À l’aide de la chandelle hydraulique.
Sangler le cadre support de l’ensemble machine électrique - réducteur (1).
Reposer :
  • Les 2 vis (6)
  • Les vis (5), (4)
Déposer la sangle .
Agrafer les faisceaux électriques  (en "a", "b").
Mettre en place la pompe à vide électrique (3).
Agrafer :
  • Les faisceaux attenants au cadre support de l’ensemble machine électrique - réducteur (1)
  • Les durits de refroidissement attenant au cadre support de l’ensemble machine électrique - réducteur (1)
Reposer :
  • L’ensemble machine électrique - réducteur
  • Le calculateur de contrôle machine électrique
  • Le chargeur embarqué
  • Le boîtier de jonction
  • La batterie de servitude
5. Opération complémentaire
Remplir et purger le circuit de refroidissement .
Remplir et parfaire le niveau d’huile dans le réducteur .
Vérifier le bon fonctionnement du véhicule sur le pont élévateur.
Effectuer un essai routier.
