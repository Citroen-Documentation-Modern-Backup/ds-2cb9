C4BG011ZP0Dépose - Repose : Faux plancher
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage préconisé
Figure : e5ap30wd
[1] Outil de dégarnissage (-).1350-ZZ.
2. Opérations préliminaires
Déposer la banquette arrière .
3. Présentation
Figure : c4bm17yd
(1) Faux plancher.
"a" Zones de collage.
4. Dépose
Figure : c4bm17zd
Déposer (Opération symétrique) :
  • Les agrafes ( en "b") ; À l’aide de l’outil [1]
  • L’enjoliveur (2) (Faux plancher)
Figure : c4bm180d
Opération symétrique :
  • Déposer les vis (3)
  • Déclipper : La garniture de seuil de porte latérale coulissante (4) ( en "c") ; À l’aide de l’outil [1]
  • Déposer : La garniture de seuil de porte latérale coulissante (4)
Figure : c4bm181d
Déposer :
  • Les douilles à sertir (5)
  • Les vis (6)
  • Les entretoises
Figure : c4bm182d
Mettre le véhicule sur un pont élévateur.
Sangler le véhicule sur le pont élévateur.
Placer une barre entre le faux plancher (1) et la caisse.
Exercer une tension sur la barre (suivant flèche ) ; À l’aide d’un cric.
Utiliser l’un des appareils de chauffage suivants :
  • Chauffage à induction (Voir catalogue outillage standard)
  • Pistolet à air chaud
  • Chalumeau
Chauffer les zones (en "d") pour permettre le décollement du faux plancher (1).
Déposer : Le faux plancher (1).
NOTA : Remplacer systématiquement : Le faux plancher (1).
5. Repose
5.1. Faux plancher sur une caisse après réparation
Figure : c4bm17yd
Éliminer les résidus de colle sur caisse.
Dégraisser les surfaces de collage sur faux plancher (1) et caisse ; À l’aide d’un dégraissant indice J1.
Appliquer une colle structurale : indice "B8" (Cordons de diamètre 8 sur les zones ) ( en "a").
Centrer - Coller : Le faux plancher (1).
Sertir le faux plancher (1) sur la caisse avec des douilles à sertir ; À l’aide d’une sertisseuse avec un embout M12 mm.
Reposer les vis (6).
Procéder dans l’ordre inverse des opérations de dépose.
5.2. Faux plancher sur une caisse neuve
Figure : c4bm17yd
Dégraisser les surfaces de collage sur faux plancher (1) et caisse ; À l’aide d’un dégraissant indice J1.
Appliquer une colle structurale : indice "B8" (Cordons de diamètre 8 sur les zones ) ( en "a").
Centrer - Coller : Le faux plancher (1).
Sertir le faux plancher (1) sur la caisse avec des douilles à sertir ; À l’aide d’une sertisseuse avec un embout M12 mm.
Reposer les vis (6) (Avec un produit frein filet).
Procéder dans l’ordre inverse des opérations de dépose.
6. Opérations complémentaires
Serrer :
  • Les vis (3) à 0,7 ± 0,1 m.daN
  • Les vis (6) à 1 ± 0,1 m.daN
Reposer : La banquette arrière .
Vérifier le fonctionnement des différents équipements.
