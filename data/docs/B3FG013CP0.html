B3FG013CP0Dépose - Repose : Disque de frein avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Remplacer systématiquement les plaquettes de frein lors du remplacement des disques.
1. Outillage
Matériel: Pince de type (FACOM DA).
2. Dépose
Débloquer les vis de roues.
Lever et caler l’avant du véhicule.
Déposer :
  • Les vis de roues avant
  • Les roues avant
  • Les plaquettes de frein
Figure : b3fg2i4d
IMPERATIF : Ne pas réutiliser les vis (2) après démontage.
Déposer :
  • Les 2 vis (2)
  • Le support d’étrier de frein (1)
Figure : b3fg2i5d
Déposer :
  • Les 2 vis (3)
  • Le disque de frein (4)
3. Nettoyage
ATTENTION : Ne pas utiliser d’air comprimé pour nettoyer les freins.
3.1. 1ère possibilité
Nettoyer le disque et l’étrier de frein à l’aide d’un produit nettoyant frein recommandé .
Laisser sécher et égoutter.
Essuyer avec un chiffon en papier.
3.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué (Voir classeur Matériels et Équipement d’atelier).
4. Contrôle
Contrôler visuellement :
  • L’étanchéité autour du piston d’étrier de frein
  • Le bon état et l’ajustement parfait des soufflets de protection
  • L’usure des disques de frein
Remplacer les pièces défectueuses.
ATTENTION : Aucune trace de graisse, d’huile, de lubrifiant n’est tolérée sur les garnitures des plaquettes de frein.
5. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Système de freinage
  • Roues
ATTENTION : Lors de chaque dépose, remplacer systématiquement les vis (2) ; Lors de chaque dépose, nettoyer systématiquement le taraudage des vis (2).
NOTA : Ces vis sont préenduites d’un agent d’étanchéité et de freinage.
Reposer :
  • Le disque de frein (4)
  • Les 2 vis (3) (Neuve)
  • Le support d’étrier de frein (1)
  • Les 2 vis (2)
  • Les plaquettes de frein
  • Les roues avant
  • Les vis de roues avant
  • Le véhicule sur ses roues
ATTENTION : Donner plusieurs coups de frein, doucement et progressivement, moteur tournant, avant de faire rouler le véhicule .
Contrôler le niveau de liquide de frein et le compléter si nécessaire.
Vérifier le bon fonctionnement des freins.
