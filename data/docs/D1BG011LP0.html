D1BG011LP0Dépose - Repose : Démarreur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
IMPERATIF : Laisser refroidir la ligne d’échappement ; Avant toute intervention sur le démarreur.
Mettre le véhicule sur un pont élévateur.
Débrancher la batterie .
Figure : b1bm0etd
Déclipper et écarter le boîtier maxi-fusibles (3).
Déposer :
  • Le déflecteur d’air (4)
  • Le résonateur d’air (5)
  • La vis (1)
  • Le raccord d’entrée d’air (6)
  • Le cache batterie (2)
  • La batterie
  • Le bac à batterie
  • La protection sous moteur
Figure : d1bm00bd
Déconnecter le connecteur d’alimentation ( en "a" ).
Déposer :
  • L’écrou (8)
  • Les vis (7)
  • Le démarreur (9) (Sortir le démarreur par le dessus de la boîte de vitesses )
2. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Vérifier la présence de la goupille de centrage .
Reposer :
  • Le démarreur (9)
  • Les vis (7)
  • L’écrou (8)
Connecter : Le connecteur d’alimentation ( en "a" ).
Reposer :
  • Le bac à batterie
  • La batterie
  • Le cache batterie (2)
  • Le raccord d’entrée d’air (6)
  • La vis (1)
  • Le résonateur d’air (5)
  • Le déflecteur d’air (4)
  • La protection sous moteur
Repositionner - Clipper : Boîtier maxi fusibles (3).
Rebrancher la batterie.
NOTA : Effectuer les opérations suivantes ; Après un rebranchement de la batterie.
