Figure : e5ag08mt

2. Dépose
Débloquer les vis de roue avant.
Lever et caler le véhicule, roues avant pendantes.
Déposer :
  • Les vis de roues
  • La roue avant
Figure : b3cg0end
Déposer :
  • L’épingle (1)
  • La cage (2)
Figure : b3cg0eod
ATTENTION : Ne jamais freiner pour effectuer le desserrage ; Il y a risque de cisaillement des vis de fixation du disque de frein sur le moyeu.
Immobiliser en rotation le moyeu à l’aide de l’outil [6310-T].
Déposer :
  • L’écrou de transmission (3)
  • L’outil [6310-T]
  • Les écrous (4) et (5)
ATTENTION : Maintenir la transmission emboîtée dans la boîte de vitesses (côté gauche).
Désaccoupler la rotule inférieure de pivot ; À l’aide de l’outil [0622].
Dégager la transmission du moyeu.
Figure : b3cg0epd
ATTENTION : Remplacer systématiquement les écrous (7) et les vis (8).
Déposer :
  • Les écrous (7)
  • Les vis (8)
  • Le bras de suspension (6)
3. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Train avant
  • Transmissions
  • Roues
Reposer :
  • Le bras de suspension (6)
  • Les vis (8)
  • Les écrous (7)
Engager la transmission dans le pivot .
Accoupler la rotule inférieure de pivot ; À l’aide de l’outil [0622].
Reposer l’écrou (5).
Immobiliser en rotation le moyeu à l’aide de l’outil [6310-T].
Reposer :
  • Les écrous (4) et (3)
  • La cage (2)
  • L’épingle (1)
  • La roue avant
  • Les vis de la roue avant
  • Le véhicule sur ses roues
