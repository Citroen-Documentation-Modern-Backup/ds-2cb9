3. Réglages
Déposer le pare-boue avant .
3.1. Charnières de porte  (côté caisse)
Figure : c4cm1nsd
L’indexage (7) est démontable en le chassant ; À l’aide d’un chasse-goupille.
NOTA : La charnière inférieure de porte (6) est indexée côté caisse. Il est cependant possible de supprimer l’indexage (7) si un réglage supplémentaire est nécessaire (Jeux).
3.2. Charnières de porte  (côté porte)
L’indexage inférieur de porte avant (8) est démontable en le chassant ; À l’aide d’un chasse-goupille.
NOTA : La charnière de porte (6) est indexée côté porte. Il est cependant possible de supprimer l’indexage (8) si un réglage supplémentaire est nécessaire (Affleurement).
3.3. Charnières de porte
Figure : c4cg0kfd
Le réglage des jeux de la porte avant s’effectue sur les charnières fixes maintenues par les vis (9), (10).
NOTA : L’accès aux vis de porte (9) s’effectue par le pare-boue (avant).
3.4. Gâche de porte avant
Figure : c4cm1nud
ATTENTION : Il est cependant possible de supprimer l’indexage (13) si un réglage supplémentaire est nécessaire.
Desserrer d’un quart de tour les vis (11) pour permettre la fermeture de la porte sans contrainte par la gâche (12).
Dégager la gâche (12) de porte avant (1).
Couper les pions d’indexage (13) ; À l’aide d’une scie à métaux.
