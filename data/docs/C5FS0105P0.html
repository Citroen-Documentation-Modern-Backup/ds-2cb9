1. Outillage préconisé
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350-ZZ.
2. Opération préliminaire
Déposer :
  • La planche de bord
  • Le combiné
  • L’écran multifonction
  • L’autoradio
  • Le chargeur CD  (suivant équipement)
  • Le coussin gonflable passager
  • Les aérateurs de planche de bord
  • Les tweeters de planche de bord
  • Le vide-poches  (conducteur)
  • Le faisceau planche de bord
3. Déshabillage
Figure : c5fm0mzd
Déchausser le joint (1) et le faire coulisser (suivant flèche ).
Déposer le joint (1).
Figure : c5fm0n0d
Déclipper la garniture (2) (en "a") ; À l’aide de l’outil [1].
Déposer la garniture (2).
Figure : c5fm0n1d
Déposer les vis (4) (Traverse de planche de bord (3)).
Figure : c5fm0n2d
Déposer les vis (5) (Traverse de planche de bord (3)).
Dégager : La traverse de planche de bord (3) (Avec précaution).
Déposer : La traverse de planche de bord (3).
4. Habillage
Procéder dans l’ordre inverse des opérations de déshabillage.
Serrer les vis (4), (5) à 0,8 ± 0,1 m.daN.
Vérifier le fonctionnement électrique des équipements.
